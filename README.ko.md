# x-nonfollowers

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | 한국어

X(구 Twitter)에서 "나는 팔로우했는데 상대는 맞팔하지 않은" 사람을 찾아주는 도구입니다. 사용법은 두 가지, 원하는 쪽을 고르세요.

- **방법 A(추천): 브라우저 유저스크립트.** 표시가 두 가지입니다. ① 팔로잉 목록을 열면 맞팔하지 않은 사람 아바타 아래에 빨간 "未回关(맞팔 아님)" 표시가 바로 뜹니다. ② 글을 볼 때, 내가 팔로우한 작성자 아바타 아래에 초록 "已关注(팔로잉 중)" 표시가 뜹니다. 보이는 그대로가 결과입니다.
- **방법 B: 데이터 아카이브 비교 스크립트.** 스크립트를 설치하기 싫다면 X 공식 데이터 아카이브를 오프라인으로 비교해 명단을 뽑습니다.

둘 다 공식 API를 쓰지 않고, 크롤링도 하지 않습니다. 스크립트 A는 추가 네트워크 요청조차 보내지 않습니다.

---

## 방법 A: 팔로잉 목록 표시 스크립트

파일: [`userscript/x-follow-badge.user.js`](userscript/x-follow-badge.user.js)

### 원리

X 웹은 사실 두 사람의 팔로우 관계를 이미 알고 있습니다(프로필에 뜨는 "나를 팔로우함" 안내가 증거입니다). 다만 목록과 타임라인에 표시하지 않을 뿐입니다. 이 스크립트는 페이지가 스스로 불러오는 데이터를 옆에서 듣고, 결과를 그 자리에 표시합니다.

- **팔로잉 목록 페이지**: 상대가 맞팔하지 않음 → 아바타 아래에 빨간 작은 알약 표시 "未回关"; 맞팔인 사람에게는 표시하지 않습니다.
- **글을 볼 때**(홈 타임라인 등): 작성자가 내가 팔로우한 사람 → 아바타 아래에 초록 표시 "已关注"; 팔로우하지 않은 작성자에게는 표시하지 않습니다.

추가 요청을 보내지 않고, 데이터를 수집하지 않고, 자동으로 언팔하지도 않습니다. 순수 표시 전용입니다. 표시 문구는 X 인터페이스 언어를 따라 자동으로 바뀝니다(중국어 간체 / English / 일본어 / 한국어). 설치 후에는 Tampermonkey가 자동으로 업데이트를 확인하니 수동으로 다시 설치할 필요가 없습니다.

### 설치

1. 브라우저에 [Tampermonkey](https://www.tampermonkey.net/) 설치(Chrome / Edge / Firefox 모두 있음; 안드로이드는 Firefox + Tampermonkey)
2. 이 저장소의 `userscript/x-follow-badge.user.js`를 열고 **Raw**를 클릭하면 Tampermonkey 설치 확인이 자동으로 뜨니 설치를 누릅니다(구버전을 이미 설치한 경우에도 같은 방법으로 새 버전으로 업데이트됩니다)
3. 내 팔로잉 목록 페이지 `x.com/내사용자이름/following`을 열어 아래로 내리며 "未回关"을 확인하고, 홈으로 돌아가 글을 보며 "已关注"을 확인합니다

### 제한

- 브라우저에서 x.com을 열었을 때만 쓸 수 있고, X 공식 앱에는 스크립트를 설치할 수 없습니다.
- "未回关"은 내 팔로잉 목록 페이지에만 뜨고, "已关注"은 글 흐름에 뜨며 내 글에는 표시되지 않습니다.
- X가 개편으로 인터페이스 필드를 바꾸면 표시가 동작하지 않을 수 있습니다. 스크립트 안에 필드 위치를 찾는 다중 폴백이 들어 있지만, 정말로 깨지면 issue를 남기거나 업데이트를 기다려 주세요.

## 방법 B: 데이터 아카이브 비교 스크립트

파일: `x_nonfollowers.py`(Python 3.8+, 표준 라이브러리만 사용, 설치할 패키지 없음)

### 먼저 데이터 아카이브 받기

X 공식 데이터 내보내기 기능, 무료입니다: 설정 및 개인정보 → 내 계정 → **데이터 아카이브 다운로드** → 비밀번호 인증 후 신청 → 생성될 때까지 대기(몇 시간에서 하루이틀) → zip 다운로드.

### 실행

```bash
# zip을 바로 넣기
python x_nonfollowers.py twitter-2026-11-10.zip

# 또는 압축을 풀고 폴더를 넣기(스크립트가 data/ 안의 파일을 자동으로 찾음)
python x_nonfollowers.py ./twitter-2026-11-10

# 명단을 표나 웹페이지로 내보내기(링크 클릭 가능)
python x_nonfollowers.py twitter-2026-11-10.zip --csv out.csv --html out.html

# 맞팔인 사람도 함께 표시
python x_nonfollowers.py twitter-2026-11-10.zip --show-mutual

# 나를 팔로우했지만 내가 맞팔하지 않은 사람도 함께 표시
python x_nonfollowers.py twitter-2026-11-10.zip --show-followers-only

# 전체 결과를 JSON으로 내보내 다른 도구에 넘기기
python x_nonfollowers.py twitter-2026-11-10.zip --json out.json
```

먼저 저장소에 들어 있는 가짜 데이터로 시험해 보세요:

```bash
python x_nonfollowers.py examples
```

### 제한

- **ID만 있고 사용자 이름은 없습니다.** X 데이터 아카이브에는 숫자 ID만 저장되는데, 이는 공식 형식의 제한입니다. 결과에 프로필 링크가 함께 나오니 클릭하면 누구인지 알 수 있습니다.
- **데이터는 신청한 그 순간의 스냅샷**입니다. 이후의 변화는 아카이브를 다시 신청해야 합니다.

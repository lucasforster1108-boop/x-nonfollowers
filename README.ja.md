# x-nonfollowers

[简体中文](README.md) | [English](README.en.md) | [繁體中文](README.zh-TW.md) | 日本語 | [한국어](README.ko.md)

X（旧 Twitter）で「自分はフォローしているのに、相手がフォローバックしていない」人を見つけるツールです。使い方は 2 つ、どちらか選んでください。

- **方法 A（おすすめ）：ブラウザ用ユーザースクリプト。** バッジが 2 種類：① フォローリストを開くと、フォローバックしていない人のアバターの下に赤い「未回关（フォローバックなし）」バッジがそのまま表示されます。② 投稿を眺めているとき、あなたがフォローしている投稿者のアバターの下に緑の「已关注（フォロー中）」バッジが表示されます。見たままが結果です。
- **方法 B：データアーカイブ比較スクリプト。** スクリプトを入れたくない場合は、X 公式のデータアーカイブをオフラインで比較してリストを出します。

どちらも公式 API は使わず、スクレイピングもしません。スクリプト A は追加のネットワークリクエストすら送りません。

---

## 方法 A：フォローリスト・バッジスクリプト

ファイル：[`userscript/x-follow-badge.user.js`](userscript/x-follow-badge.user.js)

### 仕組み

X の Web 版は、そもそも二人のフォロー関係を知っています（プロフィールに出る「フォローされています」がその証拠です）。ただリストやタイムラインには表示しないだけです。このスクリプトはページが自分用に読み込むデータを傍聴し、結果をその場に表示します。

- **フォローリストページ**：相手がフォローバックしていない → アバターの下に赤い小さなバッジ「未回关」；相互フォローの人には何も付けません。
- **投稿を見ているとき**（ホームタイムラインなど）：投稿者があなたがフォローしている人 → アバターの下に緑のバッジ「已关注」；フォローしていない投稿者には何も付けません。

追加のリクエストは送らず、データも集めず、自動でフォロー解除することもありません。表示専用です。

### インストール

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) を入れる（Chrome / Edge / Firefox 対応；Android は Firefox + Tampermonkey）
2. 本リポジトリの `userscript/x-follow-badge.user.js` を開いて **Raw** をクリックすると、Tampermonkey のインストール確認が出るので「インストール」（旧版を入れている場合も同じ手順で新版に更新されます）
3. 自分のフォローリストページ `x.com/あなたのユーザー名/following` を開いて下にスクロールし「未回关」を確認；ホームに戻って投稿を眺めながら「已关注」を確認

### 制限

- ブラウザで x.com を開いているときだけ使えます。X 公式アプリにはスクリプトを入れられません。
- 「未回关」が出るのは自分のフォローリストページだけです。「已关注」は投稿の流れに出ますが、自分の投稿には付きません。
- X の改版でインターフェースのフィールドが変わると、バッジが効かなくなることがあります。スクリプト側でフィールド位置のフォールバックを何重にも用意していますが、本当に壊れたら issue を立てるか更新をお待ちください。

## 方法 B：データアーカイブ比較スクリプト

ファイル：`x_nonfollowers.py`（Python 3.8+、標準ライブラリのみ、インストール不要）

### まずデータアーカイブを取得

X 公式のデータエクスポート機能、無料です：設定とプライバシー → アカウント → **データのアーカイブをダウンロード** → パスワードを確認してリクエスト → 生成されるまで待つ（数時間から 1〜2 日）→ zip をダウンロード。

### 実行

```bash
# zip をそのまま渡す
python x_nonfollowers.py twitter-2026-11-10.zip

# 解凍してフォルダを渡してもよい（data/ の中はスクリプトが自動で探す）
python x_nonfollowers.py ./twitter-2026-11-10

# リストを表や Web ページに書き出す（リンクをクリック可能）
python x_nonfollowers.py twitter-2026-11-10.zip --csv out.csv --html out.html

# 相互フォローの人も一緒に表示
python x_nonfollowers.py twitter-2026-11-10.zip --show-mutual
```

まずリポジトリ同梱のダミーデータで試せます：

```bash
python x_nonfollowers.py examples
```

### 制限

- **ID のみで、ユーザー名はありません。** X のデータアーカイブには数字の ID しか入っていない、公式形式の制限です。結果にはプロフィールリンクが付くので、クリックすれば誰か分かります。
- **データはリクエストした時点のスナップショット**です。その後の変化は、アーカイブを取り直す必要があります。

## プライバシー

どちらのツールも、処理はすべてあなたのローカルで完結します。データアーカイブはアカウントの全データを含むので、誰にも共有しないでください。
